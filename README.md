# CaterFlow

> **Catering & Event Rental Management SaaS** — A mobile-first, soft-monochromatic operating system for catering businesses and event-service companies to manage customers, events, food menus, quotations, light & sound rentals, staff, purchases, expenses, and event profitability.

---

## ✨ Features

- **Event-Centric Architecture**: Every quotation, menu, staff roster, rental, and payment connects directly to an event.
- **Unified Quotation Builder**: Add reusable food menus (with automatic rate × guest count calculation), live counters (e.g. Dosa counters), and light & sound packages to the same quotation.
- **Interactive 3-Part Menu Builder**: Design multi-course catering menus with live pricing models (per-person, package, custom).
- **Light & Sound Rental Inventory**: Manage concert line arrays, moving head beams, wireless mics, and pre-packaged AV rigs.
- **Client Document Preview & 1-Click Conversion**: Generate minimal client-ready quotes with PDF print layout and 1-click conversion into confirmed events with advance payment logging.
- **Event Profitability Tracker**: Real-time margin calculation without complicated accounting terminology ($Revenue - Costs = Profit$).
- **Role Perspective Switcher**: Switch between Company Owner, Catering Manager, Sales Staff, and Kitchen Staff.
- **Mobile-First UX**: Native bottom navigation, bottom sheets, 2x2 metric cards, and touch-optimized controls.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/haxord-workspace/cater-flow.git
cd cater-flow

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5175](http://localhost:5175) or [http://localhost:5176](http://localhost:5176) to view the app in your browser.
